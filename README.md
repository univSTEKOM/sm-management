# SM Management
Project Title: SM Management

Project Overview: This project manages SM (Social Media?) users and tasks, tracking key metrics such as followers, posts, and likes.

Key Features:

User Management: Add, edit, and view user details.

Task Management: Create and track tasks associated with users.

Metrics Tracking: Input and monitor numerical values (followers, posts, likes).

Technical Stack: Built with Go and HTMX for a dynamic, server-rendered interface.
